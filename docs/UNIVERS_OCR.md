# Univers OCR — Visible Research Entry

## Purpose

**Univers OCR** is the visible cover name for the UPI research stream on image information integrity, OCR/decode, reconstruction, Mirror/Duality analysis, and Shadow auditing.

The name is intentionally discoverable. This work must not be hidden or buried under an opaque internal label.

## Core principle

```
SOURCE
→ PROVENANCE
→ DECODE
→ MIRROR
→ CROSS-VERIFY
→ CLASSIFY
→ RECONSTRUCT
→ AUDIT
```

Never:

```
IMAGE → GUESS → SOURCE
```

## Information integrity

Original source evidence has priority over transformed representations.

```
ORIGINAL > LOSSLESS COPY > CONTROLLED DEGRADATION > ORDINARY EDIT > AI-ENHANCED > AI-GENERATED
```

This is an evidence/provenance hierarchy, not a quality ranking.

AI-enhanced images may introduce or alter details. They are therefore secondary references unless independently verified.

## Digital Shredder

A controlled degradation test creates known information loss:

```
I₀ → D₁(I₀) → D₂(I₀) → D₃(I₀)
```

Track loss separately for text, symbols, geometry, position, scale, frequency, colour, and texture.

The purpose is to measure reconstruction limits without confusing generated detail with source evidence.

## Mirror / Duality

Mirror is an explicit comparison operator:

```
M(A)=A'
```

Compare:

```
A ↔ M(A)
```

and record invariants, asymmetries, transformations, and conflicts.

For an operator Ω:

```
Δ = MΩ(X) - ΩM(X)
```

A non-zero Δ is an observation requiring analysis. It is not by itself proof of new physics.

## Shadow Layer

Shadow is a read-only audit layer containing information that the main path might discard:

- alternative OCR results
- ambiguous readings
- conflicts
- rejected matches
- lost details
- AI-generated details
- negative results
- alternative reconstructions
- unused signals

Shadow may flag information for review but must not silently convert an alternative into fact.

```
MAIN ↔ MIRROR ↔ CROSS-CHECK ↔ SHADOW
```

## Evidence classes

- AMB — ambiguous

## Stop gate

If evidence cannot distinguish between competing interpretations:

```
UNCERTAINTY > THRESHOLD → STOP
```

Do not select an interpretation merely because it fits the current theory.
