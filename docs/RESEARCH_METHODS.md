# UPI research methods

Research mode is the place where exploratory methods can run before a proposal
has a known destination. The methods are recorded as methods, not silently
promoted into physics.

| Method | Research use | Shadow output |
| --- | --- | --- |
| Whole-function reconstruction | Read the proposed system before splitting it into claims | Candidate map |
| Dimensional analysis | Check units and constants | Pass/fail boundary |
| Forward derivation | A -> ... -> Z | Derived subchain |
| Reverse reconstruction | Z -> ... -> A | Round-trip consistency or boundary |
| Limit/edge testing | Test 0 Hz, high-frequency, small/large scale, null cases | Open boundary or contradiction |
| Frequency comparison | Compare 7.834 Hz and 8 Hz without declaring either universal | Numeric relation and beat candidate |
| Log-scale measurement | Use the image's 10^0 ... 10^15 LY scale to parameterize a spiral | Fitted/exploratory geometry |
| Functional analogy | Compare systems that appear to perform the same function | FORM_SIMILAR / SYM lead |
| Cross-domain mapping | Frequency, energy, mass, rotation, wave, geometry | Explicit typed bridges |
| Simulation | Explore consequences under declared assumptions | simulation result only |
| Web/source research | Find established equations, measurements, and counterexamples | provenance |
| Image inspection | Extract equations, labels, geometry, and scale markings from diagrams | source-derived inputs |
| Shadow audit | Preserve failed branches, conflicts, warnings, and successful submaps | audit trail |
| Null model | Compare the proposed relation against a simpler known model | discriminating test |
| Falsification design | State what observation would kill the bridge | HYP test metadata |

## The operating rule

Research mode should answer:

1. What can we calculate now?
2. Which sub-maps survive the declared checks?
3. Where is the first boundary?
4. Which branches have no connection yet?
5. What is the smallest next test?

It should not answer "therefore the whole theory is true" merely because one
sub-chain closes.

## Open graph, not forced loop

A research session is allowed to end as:

    A -> B -> C
         \
          -> unknown
                 \
                  -> future test

The unknown branch is valuable data. It is not a failure of the research mode.

A closed loop can be recorded when an actual closure test exists. Until then,
connected nodes are a connected subchain, not a proven closed physical loop.
