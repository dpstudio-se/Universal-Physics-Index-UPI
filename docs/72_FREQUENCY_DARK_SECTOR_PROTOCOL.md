# 72-Frequency Dark-Sector Research Protocol

Status: **HYP**. This document is a research construction, not a claim that dark matter has been confirmed.

## 1. Geometry

The 72-motor starts from one full phase cycle:

`Delta theta = 2*pi/72 = 5 degrees`.

The proposed bookkeeping chain is:

`72 -> 144 -> 288 -> 360`

with the last relation

`360 - 288 = 72`.

The "bridge" is therefore retained as an explicit geometric relation. It is not treated as a physical force until a dynamical operator is supplied.

## 2. Frequency layer

Use a continuous phase field:

`theta_t = 2*pi*f(r,t)`

and

`Phi(r,t) = A(r,t) exp(i*theta(r,t))`.

At the declared reference coordinate 7.834125 Hz:

- period = 0.1276466740 s
- one 72-phase interval = 0.00177287047 s
- offset to 8 Hz = 2.1173392 %
- mass-equivalent of one h*f quantum = 5.77570656e-50 kg

These are arithmetic results, not evidence of dark matter.

## 3. Physical closure requirement

The missing physical step is an explicit Lagrangian or stress-energy tensor. The candidate must produce a conserved positive energy density:

`nabla_mu T^(mu nu) = 0`

and a gravitational source that can be inserted into the reference equations.

No density profile is allowed to be chosen merely because it fits a galaxy.

## 4. Blind galaxy test

Use the official SPARC sample of 175 disk galaxies.

For each galaxy:

1. Read only independently supplied baryonic inputs and uncertainties.
2. Generate the 72-field prediction.
3. Freeze the global parameter set.
4. Predict the rotation curve.
5. Only then reveal observed velocities for scoring.
6. Compare against:
   - baryons-only Newtonian model;
   - a standard halo reference;
   - phase-count controls N = 48, 60, 84, 96;
   - continuous-phase control.

Primary score should be declared before the run, e.g. RMS residual in log acceleration with uncertainty weighting.

## 5. What would count as a real result

A useful result requires all of the following:

- 72 is selected without fitting it to the target rotation curves.
- The field equations are dimensionally and dynamically closed.
- Parameters are global rather than per-galaxy.
- Held-out galaxies show predictive improvement.
- The result survives neighboring-N controls.
- The model passes independent lensing and cosmological constraints.
- An independent implementation reproduces the result.

Only then should the UPI status move beyond HYP.

## 6. What remains open

The current construction does **not** yet derive `rho_Phi(r)` from first principles. Therefore it cannot yet claim a dark-matter confirmation.

The next mathematical target is:

`72-phase field -> Lagrangian -> stress-energy tensor -> rho_Phi(r) -> rotation curve`.

That is the actual bridge we need to solve.
