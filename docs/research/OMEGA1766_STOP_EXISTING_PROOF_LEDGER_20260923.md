## Symmetric audit rule

For the same proposition and the same assumptions, apply the same evidentiary standard to Ω1766 and established formulations.

```
same claim + same assumptions
        ↓
same mathematical / empirical standard
        ↓
existing proof reused when the proposition is identical
        ↓
new burden only begins at the first genuinely new proposition
```

A theory's age, prestige, or prior acceptance is not itself evidence. Conversely, mathematical resemblance alone is not proof of physical identity.

## Anti-double-standard check

Rejecting a result solely because it was obtained through Ω1766 is not a valid evidentiary criterion.

Likewise, accepting an Ω1766 result solely because it resembles an established equation is not valid.

The audit therefore tests the proposition, assumptions, derivation, prediction and observation independently of the name of the framework.
