## Layer boundaries

**TF1766→2026** is a reference/legal-source layer, not a physics equation.

**PHYSICS KNOWLEDGE** is the established-knowledge layer and must preserve provenance and units.

**NORM M GENERATOR** creates machine-readable validation rules. A generated norm is a software rule, not automatically a scientific law.

**RNA ENGINE** performs dynamic analysis against declared inputs.

**Ω7834** remains a declared model/reference frequency. The value 7.834125 Hz is not promoted to a universal constant by this architecture.
