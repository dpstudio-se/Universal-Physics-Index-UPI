# AI ↔ UPI → ∞ Taurus v1

## Purpose

This architecture binds an AI workload to UPI without allowing the AI to become the source of truth.

AI → BRIDGE → UPI → FL-M → TAURUS → AI

**Taurus** is the project name for the toroidal closure layer. It means recursive continuation around a bounded state surface, not a claim of literal physical infinity.

## Three layers

### AI / RNA
- extract
- derive
- transform
- calculate
- propose
- compare
- generate next workload

AI output is always a proposal until it crosses the UPI gates.

### UPI / DNA
UPI remains the canonical evidence and provenance boundary:
- EST: established within declared domain
- DER: derived
- HYP: falsifiable hypothesis
- STOP: missing proof, mechanism or observation
- ERR: invalid, contradicted or superseded
- SYM: symbolic interpretation or analogy

Canonical DNA is versioned. AI cannot silently rewrite it.

### Taurus / ∞
Taurus is the continuation controller:

state_n → proposal_n → verify_n → delta_n → state_(n+1) ↺

The infinity symbol means continuation is available when a new workload frontier exists. It does not mean an infinite physical-energy source or an automatically successful scientific loop.

## Ω1766 binding
Ω1766 = T ∘ B ∘ R

Taurus uses it as an audit/transition pattern:
- T: transport the candidate and provenance
- B: cross the AI ↔ UPI boundary under declared conditions
- R: return the verified delta as the next state

The operator remains a project model, not an SI law.

## Gate sequence
1. SOURCE: retain the original input.
2. EXTRACT: split claims and workload.
3. CLASSIFY: assign domain and scientific status.
4. BRIDGE: bind AI output to UPI records and provenance.
5. MIRROR: run independent or structurally separate reverse checks.
6. VERIFY: execute applicable schema, math, unit, domain and falsification checks.
7. DELTA: compute what actually changed.
8. PROMOTE: only verified, reviewable changes can enter canonical DNA.
9. CONTINUE: generate the next workload frontier.
10. STOP: if no new information or a required gate is missing.

## Invariants
- AI is not evidence merely because it produced an answer.
- A successful software test is not experimental verification.
- SYM/HYP never silently become EST.
- ERR/STOP remain visible and traceable.
- Provenance survives every transformation.
- No-new-information terminates the current frontier.
- Non-invertible transformations do not receive a fabricated inverse.
- Canonical promotion remains review-gated.

## Compact state model
Let D_n be canonical DNA, W_n the active workload and S_n the shadow/quarantine state.

candidate = AI(W_n, D_n, S_n)
bridge = B(candidate, provenance)
report = VERIFY(bridge)
delta = report.delta
D_(n+1) = D_n + delta_verified
W_(n+1) = next_frontier(report)
S_(n+1) = preserve_unresolved(report)

If delta_verified is empty and there is no new observation, the frontier stops.

## What ∞ Taurus is not
- a perpetual-motion claim
- a claim that software creates energy
- a claim that every recursive loop converges
- a replacement for human review
- a promotion path from hypothesis to established physics

It is an architecture for continuous, bounded, auditable AI↔UPI iteration.
