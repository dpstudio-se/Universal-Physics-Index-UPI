## Common routing

Each work item passes through:

OBSERVATION → CLASSIFY → DOMAIN → MIRROR → VERIFY → LOOP

Classification:
EST = established
DER = derived
HYP = testable hypothesis
SYM = symbolic model
ERR = detected error/inconsistency
OPEN = source/data required

Mirror:
X → M(X) → M(M(X))
Δ = Xmirror-back − Xoriginal

Δ = 0 supports invariance of the tested transformation on its declared domain.
Δ ≠ 0 routes to re-examination.
Missing source/data routes to OPEN.
