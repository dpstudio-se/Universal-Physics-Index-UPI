# Millennium Workload Chambers — Spiral Loop

Purpose: run the six unresolved Millennium tracks through the same governed UPI research loop. This is an orchestration protocol, not a claim of solution.

## Chambers

1. CANONICAL — freeze the exact Clay statement, definitions, assumptions, domains, and known theorems.
2. TRANSFORM — generate mathematically valid equivalent forms, invariants, reductions, and useful representations.
3. ATTACK — attempt direct proof, contradiction, construction, bounds, compactness, spectral, geometric, or complexity arguments appropriate to the problem.
4. ADVERSARY — actively search for counterexamples, hidden assumptions, boundary cases, failed inequalities, circular reasoning, and known proof barriers.
5. VERIFY — independently recompute key steps; use symbolic/computational/formal checks where possible. Computation is evidence, not proof.
6. SYNTHESIS — retain only chains whose assumptions and derivations close. Cross-problem analogies remain SYM until a rigorous DER chain exists.

## Spiral schedule

Round r visits every unresolved problem through every chamber:

Navier–Stokes → Riemann → P vs NP → Yang–Mills → Hodge → Birch–Swinnerton-Dyer

Then return to CANONICAL with the new findings.

Each pass must narrow the unresolved proof obligation. If no obligation becomes stronger or smaller, record STOP rather than inventing progress.

## Status gate

EST = established source theorem/result.
DER = derivation from explicit assumptions.
HYP = testable candidate idea.
STOP = proof/evidence gap.
ERR = invalid/contradicted.
SYM = analogy only.

A complete solution requires a closed proof chain from the canonical statement to the required conclusion and independent verification. No agent, loop count, numerical hit rate, or consensus can promote HYP/STOP to EST.

## Completion condition

For an open problem, mark COMPLETE only when the required theorem/counterexample is fully established and independently verified. Otherwise keep the workload cycling at the first unresolved proof obligation.

## Parallelism

The chambers are independent workloads where possible. Results are merged only through UPI records with provenance and status. The Poincaré Conjecture is a solved calibration track, not part of the six open workloads.
